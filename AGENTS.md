# Test website editing

This is a permanent test website with synthetic content. Work only in this
repository. Keep account details and credentials out of files and Git.

Read SITE_GUIDE.md before editing. Use npm run check and npm run build to verify
a change. Follow the editing application instructions for saving to preview.
Publishing is performed through the application, not by the editing model.
Do not change the production branch, security headers or selection bridge to
complete a content or font request. Preserve unrelated work.
