## Checks

- Text-only edits: validate touched JSON, merge translation fragments and check affected mirror HTML content and links. Report which checks actually ran; source checks do not prove rendering or external delivery.
- Image or source edits: run `npm run check` when available. Structural changes on rebuilt or mirrored sites, including page/registry/navigation changes, also require `npm run build` when available. Inspect the actual package scripts; a build does not establish deployment readiness.
- `npm run merge` — after editing a translation fragment.
